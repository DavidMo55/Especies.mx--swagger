# Especies.mx — Swagger API-07

Documentación de `GET /api/v1/descubrir`.

## Ejecutar

```sh
npm ci
npm start
```

Abrir http://localhost:8080. Puerto alternativo: `PORT=8081 npm start`.
Detener con Ctrl+C. Editar `openapi.json` y recargar para ver cambios.

Los recursos de Swagger UI se sirven localmente.
Este proyecto documenta el contrato; no implementa el backend ni consulta la BD.
La ejecución de solicitudes está desactivada hasta contar con el servicio.
